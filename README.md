# Isabella Franklin - Terapia e Mentoria

Uma landing page elegante e moderna desenvolvida para a **Dra. Isabella Franklin**, psicóloga clínica e mentora. O projeto foi construído com foco em proporcionar uma experiência de acolhimento e profissionalismo para mulheres que buscam autoconhecimento e desenvolvimento emocional.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores e mais modernas tecnologias de desenvolvimento web:

- **React 19**: Biblioteca principal para construção da interface.
- **Vite**: Build tool extremamente rápida para desenvolvimento moderno.
- **Tailwind CSS**: Framework de CSS utilitário para um design responsivo e personalizado.
- **Framer Motion**: Biblioteca de animações para criar transições suaves e interativas.
- **Lucide React**: Conjunto de ícones minimalistas e elegantes.
- **Lucide Icons**: Conjunto de ícones para complementar a identidade visual.

## ✨ Funcionalidades

- **Splash Screen**: Tela de carregamento personalizada com a identidade visual da profissional.
- **Design Responsivo**: Totalmente otimizado para dispositivos móveis, tablets e desktop.
- **Animações Fluidas**: Entradas e transições suaves que guiam a atenção do usuário.
- **Navegação Inteligente**: Menu fixo com efeito de transparência ao rolar.
- **Integração de Links**: Acesso facilitado para agendamentos, WhatsApp e redes sociais.

## 📦 Como Rodar Localmente

1. **Clonar o repositório**
2. **Instalar as dependências**:
   ```bash
   npm install
   ```
3. **Executar o ambiente de desenvolvimento**:
   ```bash
   npm run dev
   ```
4. **Abrir no navegador**: Acesse `http://localhost:5173`.

## 🌐 Deploy na Vercel

O projeto está pronto para ser publicado na Vercel!

1. Conecte seu repositório GitHub ao painel da Vercel.
2. A Vercel detectará automaticamente as configurações do Vite.
3. Configure os comandos de build:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Clique em **Deploy**.

O arquivo `vercel.json` incluído no projeto garante que as rotas e assets funcionem perfeitamente no ambiente de produção.
